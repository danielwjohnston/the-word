# Jude, Unfolded

*An Exploration of Every Verse, Word, Image, and Meaning*

A book-length expository commentary on the Epistle of Jude for thoughtful readers without academic training. It works from the Greek text and its earliest manuscripts first, prints every verse in eighteen free English translations without preferring any of them, and prints in full every passage of Scripture it cites.

Everything in the book is free: every source is in the public domain or under CC0, CC BY, or CC BY-SA, and the book itself is released under **CC BY-SA 4.0** (copyleft). The governing rules are in [`project-brief.md`](project-brief.md).

## Read the book

- **`manuscript.md`**: the assembled book, with Scripture references linked to the passages printed in each chapter's section L.
- **`exports/`**: EPUB, DOCX, PDF, and HTML generated from `manuscript.md`.
- **`chapters/`**: front matter, the 13 main chapters, and the afterword (the working sources of the manuscript).
- **`appendices/`**: textual variants, disputed interpretations, the Jude–2 Peter parallels, glossary, indexes, and licensing acknowledgments.
- **`bibliography.md`**: every work used, all free and all consulted directly.

## How each chapter is built

| Section | Content | Source |
|---|---|---|
| A. The Text | SBLGNT Greek; readings of ten manuscripts (P72, P78, ℵ, A, B, C, K, L, Ψ, 1739); the verses in 18 free translations | Generated by `tools/make_texts.py` |
| B–K | Orientation, phrase-by-phrase exploration (Greek-first headings), original language, history, connections, questions, the passage within Jude, application, discussion, sources | Written commentary |
| L. Texts Highlighted | Every cited passage in the original language (WLC Hebrew, SBLGNT Greek, or LXX), then BSB and WEB; 1 Enoch in Charles's translation | Generated by `tools/make_texts.py` |

Generated regions sit between `<!-- BEGIN GENERATED … -->` and `<!-- END GENERATED … -->` markers and are rebuilt on every build. Edit the commentary outside them.

## Tools

```bash
tools/fetch_sources.sh                 # download the openly licensed source texts into .cache/
python3 -I tools/make_texts.py         # rebuild sections A and L, the overview text, and the variants table (checks every manuscript claim)
python3 -I tools/audit.py              # coverage, quotation, footnote, and structure audits; blocks excluded translations
python3 -I tools/greek_audit.py        # every Greek form checked against SBLGNT, LXX, RP/TR, and Abbott-Smith
python3 -I tools/build.py              # regenerate everything, assemble manuscript.md, export EPUB/DOCX/PDF/HTML
python3 -I tools/lsv.py JUD1:1-2       # print verses exactly (for quoting)
```

`tools/build.py` needs `pandoc`. The PDF export uses the Chromium installed with Playwright.
